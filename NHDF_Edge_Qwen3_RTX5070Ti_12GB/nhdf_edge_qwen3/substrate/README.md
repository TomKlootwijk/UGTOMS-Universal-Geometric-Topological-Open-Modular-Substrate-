# UGTOMS substrate boundary

This directory is a compact grounding set, not a dump of every historical
application. It preserves the reusable geometric-topological machinery and
keeps later profiles, evidence, and proposals visibly separate.

The semantic base is the normalized NHDF v0.1 closure together with the early
UGTS typed algebra. UGTS 3.6 contributes a content-addressed definition graph;
SCLP 3.6.2 is a first-class corrective profile for swept-cone/log-polar
packing. The UGTS-GN support/compatibility/guard chain is an execution and
event-admission discipline, not the identity of the whole substrate. NHDF v0.3
CCD is a selectable later profile.

The kernel is a finite, typed, deterministic generative system. Geometry and
kinematics may use declared IEEE-754 reference calculations, but discrete
identity, topology, packed addressing, routing, and lineage are integer- or
hash-defined. Numeric uncertainty is an explicit interval or
`INDETERMINATE` result, never fuzzy truth.

Directory roles:

- `kernel/contract.json`: compact substrate identity, invariants, state, and
  deterministic execution discipline.
- `profiles/`: optional mappings that specialize the kernel without replacing
  it.
- `evidence/application_proofs.json`: small application artifacts that prove
  generative usefulness; their payloads are not imported.
- `incubator/`: future directions that are deliberately outside the kernel.
- `extensions/registry.json`: reviewed proposal state. Nothing self-promotes.
- `AGENT_CONTRACT.md`: self-contained instructions injected into the isolated
  local coding agent after digest verification.

The historical archive remains read-only. Equations and concepts were cleanly
reimplemented with source hashes because several historical packages have no
clear redistribution license. Entertainment, wallet, ML-teacher, GIS-provider,
build-output, and application UI layers are not substrate authority.
