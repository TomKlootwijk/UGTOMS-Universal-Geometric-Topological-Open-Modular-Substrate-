# Document status

`NHDF_Edge_Qwen3_RTX5070Ti_Report.docx` and `.pdf` are the preserved v0.1
design report. They predate the target-machine quality falsification and the
v0.3 specification supplied on 31 August 2026. They are not current validation
evidence and must not be used to claim a functional custom codec.

The current disposition is in the repository `README.md`,
`VALIDATION_STATUS.md`, and `metrics/local/`. Regenerating a formal v0.3 report
is deferred until a replacement custom codec passes the bounded comparative
gate; otherwise a polished report would only restate a rejected design.
