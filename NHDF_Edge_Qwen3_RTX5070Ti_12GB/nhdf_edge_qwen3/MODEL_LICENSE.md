# Model license and redistribution boundary

The selected source checkpoint is `Qwen/Qwen3-30B-A3B-Instruct-2507`, published
under Apache-2.0 on Hugging Face. This ZIP deliberately contains no model
weights, tokenizers downloaded from the Hub, or converted weight pack. Run the
included pull and conversion scripts locally, preserve the upstream `LICENSE`
and model card, and review any downstream deployment obligations.

The package's size projections refer to the upstream model and to a proposed
converted representation. They are not a redistributed checkpoint.
